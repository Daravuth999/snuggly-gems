# Design Tokens

Token reference for **Cozy Code Library**. Use utility classes and CSS variables — never raw values.

## Colors

Apply with any color utility: `bg-<name>`, `text-<name>`, `border-<name>`, `ring-<name>`, `divide-<name>`, etc.

| Name | CSS variable |
|---|---|
| `ink-950` | `--color-ink-950` |
| `ink-900` | `--color-ink-900` |
| `ink-800` | `--color-ink-800` |
| `ink-700` | `--color-ink-700` |
| `ink-300` | `--color-ink-300` |
| `ink-400` | `--color-ink-400` |
| `accent` | `--color-accent` |
| `accent-soft` | `--color-accent-soft` |
